🚚 Tata Motors – Small Commercial Vehicles (React UI Clone)

A responsive frontend UI clone of the Tata Motors Small Commercial Vehicles website, built using React.js with Vite.
This project focuses on recreating a modern automotive corporate website UI with clean layout, reusable components, and smooth user experience.

⚙️ Installation & Setup

Follow these steps to run the project locally:

1️⃣ Clone the repository
git clone https://github.com/sonalibastia/TataMotorsSmallTrucks.git

2️⃣ Navigate to project folder
cd TataMotorsSmallTrucks

3️⃣ Install dependencies
npm install

4️⃣ Start development server
npm run dev


Now open 👉 http://localhost:5173 in your browser.
